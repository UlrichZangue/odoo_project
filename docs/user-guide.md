# Guide utilisateur

Depuis **Support client > Opérations > Tickets**, créez un ticket puis renseignez au minimum le titre et le client. Les boutons de l'en-tête guident les transitions disponibles. Le bouton statistique **Interventions** ouvre les opérations liées.

Pour une intervention, indiquez ticket, consultant, créneau, type et diagnostic. Cliquez sur **Démarrer**, complétez les actions et le résultat, puis **Terminer**. Le nom du validateur client peut alors être horodaté. Le menu **Imprimer > Rapport d'intervention** génère le PDF.

Les filtres permettent de retrouver les urgences, les éléments ouverts ou assignés à l'utilisateur. Les regroupements par état, priorité, consultant, client et catégorie sont disponibles dans la recherche.
