# Captures d'écran

Aucune capture artificielle n'est fournie. Après installation réelle du module, ajouter ici au minimum :

1. `tickets-kanban.png` — kanban avec plusieurs priorités et états ;
2. `ticket-form.png` — formulaire, boutons de workflow et chatter ;
3. `intervention-form.png` — compte rendu complet sans donnée personnelle ;
4. `intervention-report.png` — aperçu du PDF généré.

Utiliser une base de démonstration et masquer toute information sensible avant publication.
